### 🚀 Featured projects

| Project | What it does | Built with |
| --- | --- | --- |
| **[Mendwave](https://stephenqiao.io/projects)** | A production AI speech editor — change a word in the transcript and only that span is regenerated in the original speaker's voice, machine-verified, then spliced back. *Live with paying customers.* | Speech synthesis, audio processing, AI voice modeling |
| **[OrbitDesk](https://stephenqiao.io/projects)** | A space-market intelligence terminal putting the live orbital catalog, the commercial supplier landscape, and the launch market on one console — 16,000+ objects propagated with SGP4. | SGP4, Web Workers, WebGL |
| **[Apogee](https://stephenqiao.io/projects)** | A seven-service game backend platform: skill-based matchmaking, Kubernetes session allocation, a NATS-to-Parquet telemetry pipeline, deterministic replay. | Go, Kubernetes, ArgoCD, NATS, Parquet |
| **[Paper Trail](https://stephenqiao.io/projects)** | A deterministic simulated economy that stress-tests an LLM auditor with injected accounting errors, using a bandit adversary that reweights toward whatever gets missed. | Python, LLM evals, adversarial testing |
| **[LeaseCheck](https://stephenqiao.io/projects)** | An AI auditor for residential lease PDFs that flags clauses violating landlord–tenant law and cites the specific legal rule. | RAG, pgvector, LLMs |
| **[sEMG Gesture Decoder](https://stephenqiao.io/projects)** | A real-time hand gesture classifier that decodes surface EMG as it streams in, predicting at ~1 ms latency on a causal pipeline. | Signal processing, SVM/CNN, Ninapro |

On the hardware side: a 2-DOF **robotic wrist** drawing complex shapes under PID control, a **gesture-controlled light** using computer vision on a Pi 4, and a **magnetic-field-controlled robot** timed by PIC32 interrupts at millisecond precision.
